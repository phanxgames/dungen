## Quick Start

Dungen is a procedural dungeon generator that creates game-ready dungeon maps in Tiled map format (.tmx). It generates randomized layouts with rooms, hallways, boss rooms, keys, chests, and monster encounters while ensuring all areas are reachable.

## Key Features

- Procedural generation with configurable parameters
- Boss rooms with key-based progression
- Strategic chest placement in deadends
- Monster choke points in corridors
- Tiled Map Editor integration
- Pathfinding-based room connectivity
- Multiple tile layers support
